Links were accepted after checking paper identity and author/project context. Repository links below refer to implementation repositories, not website source repositories.

## Release and verification notes

- STAC: the official repository links to https://stac-3r.github.io/.
- ABot-M0: the code link selects the ABot-M0 branch; the repository default now covers a newer model.
- DynamicVGGT: the author repository states that the released code is a reimplementation and does not include pretrained weights.
- Water-VGGT and LongStream: some release components remain pending; the code links should not be interpreted as complete training releases.
- SSR-GS: added the project page only. Its Code button points to the unrelated Nerfies template repository.
- GeoAware-VLA: added the project page only; its linked BAKU repository could not be confirmed as the paper-specific implementation.
- PaceVGGT, HeSS, DR-MV3D, AsyncEvGS, and 4D-VGGT: no new Code link was added from a placeholder or pending release. AsyncEvGS contained only a README at the time of review.
- StereoVGGT: added the project page; its website source repository is not an implementation.
- SpaceMind and Geo-EVS: matching repositories were found, but author ownership could not be confirmed independently, so no new link was added.
- No VGG-T³ implementation link was verified; similarly named repositories unrelated to the paper were excluded.
- Existing resource links were preserved. Remaining empty fields mean that this audit did not verify a suitable official link; they do not prove that no resource exists.
- A PDF-front-matter scan was attempted but did not complete reliably; its results were not used as verification evidence.
